# 스마트 경보 시스템 — 회로도

## 전체 구성 개요

라즈베리파이4의 40핀 GPIO 헤더에 LED, 부저, 조도센서(PCF8591T I2C 모듈), 7세그먼트 디스플레이를 연결한다.  
**브레드보드 1개로 모든 부품 배치 가능** (400포인트 하프 사이즈 이상).

- 동작 전압: 3.3V (GPIO 출력) / 5V (부저 VCC)
- 전류 제한 저항: 220Ω (LED·7세그먼트 각 세그먼트)
- 부저 드라이브: NPN 트랜지스터 (2N2222) — GPIO 3.3V로 5V 부저 구동

## 부품별 결선

### 1. LED (GPIO 18 — PWM 소프트웨어)

```
GPIO18 (핀12) ──[220Ω]──┬── LED(+) 애노드
                         └── LED(-) 캐소드 ── GND
```

| 연결점 | 설명 |
|--------|------|
| GPIO18 → 220Ω | 전류 제한 저항 |
| 220Ω → LED 애노드(+) | LED 긴 다리 |
| LED 캐소드(-) → GND | LED 짧은 다리 |

- PWM duty cycle: 25% (LOW) / 50% (MID) / 100% (HIGH)
- 순방향 전압 강하 약 2V, 저항으로 전류 약 5mA 제한

---

### 2. 부저 (GPIO 23 — NPN 트랜지스터 구동)

```
5V ──────────────────┬── 부저(+)
                     │
                  부저(-) ── 트랜지스터 컬렉터(C)
                                │
GPIO23 (핀16) ──[1kΩ]── 트랜지스터 베이스(B)
                                │
                        트랜지스터 이미터(E) ── GND
```

| 연결점 | 설명 |
|--------|------|
| GPIO23 → 1kΩ → 트랜지스터 B | 베이스 전류 제한 |
| 트랜지스터 C → 부저(-) | 컬렉터로 전류 스위칭 |
| 부저(+) → 5V | 능동형 부저 전원 |
| 트랜지스터 E → GND | 이미터 접지 |

- 트랜지스터: 2N2222 (또는 BC547) NPN
- GPIO 3.3V로 5V 부저 스위칭

---

### 3. 조도센서 (PCF8591T — I2C)

```
라즈베리파이 핀3 (SDA) ── 모듈 SDA
라즈베리파이 핀5 (SCL) ── 모듈 SCL
라즈베리파이 핀1 (3.3V) ── 모듈 VCC
라즈베리파이 핀6 (GND)  ── 모듈 GND
```

| 연결점 | 설명 |
|--------|------|
| SDA → GPIO2 (핀3) | I2C 데이터 |
| SCL → GPIO3 (핀5) | I2C 클럭 |
| VCC → 3.3V (핀1) | 전원 |
| GND → GND (핀6) | 접지 |

- I2C 주소: 0x48
- CDS는 모듈 내부적으로 AIN0에 연결됨
- 반환값: 0~255 (높을수록 밝음), 100 미만 시 침입 감지

---

### 4. 7세그먼트 디스플레이 (GPIO 4,17,27,22,5,6,13,19 — 공통 캐소드)

```
세그먼트 배치:
 _
|_|   a=상단, b=우상, c=우하, d=하단
|_|   e=좌하, f=좌상, g=중간, dp=소수점
```

```
GPIO4  (핀 7) ──[220Ω]── 세그먼트 a (상단)
GPIO17 (핀11) ──[220Ω]── 세그먼트 b (우상)
GPIO27 (핀13) ──[220Ω]── 세그먼트 c (우하)
GPIO22 (핀15) ──[220Ω]── 세그먼트 d (하단)
GPIO5  (핀29) ──[220Ω]── 세그먼트 e (좌하)
GPIO6  (핀31) ──[220Ω]── 세그먼트 f (좌상)
GPIO13 (핀33) ──[220Ω]── 세그먼트 g (중간)
GPIO19 (핀35) ──[220Ω]── 세그먼트 dp (소수점)

공통 캐소드(COM) ── GND
```

| GPIO (BCM) | 물리 핀 | 세그먼트 | 위치 |
|-----------|---------|---------|------|
| GPIO 4    | 핀 7   | a       | 상단 수평 |
| GPIO 17   | 핀 11  | b       | 우측 상단 수직 |
| GPIO 27   | 핀 13  | c       | 우측 하단 수직 |
| GPIO 22   | 핀 15  | d       | 하단 수평 |
| GPIO 5    | 핀 29  | e       | 좌측 하단 수직 |
| GPIO 6    | 핀 31  | f       | 좌측 상단 수직 |
| GPIO 13   | 핀 33  | g       | 중간 수평 |
| GPIO 19   | 핀 35  | dp      | 소수점 |

## 미니 브레드보드 (170포인트) 배치 가이드

170포인트 미니 브레드보드(17행 × 10열, 전원 레일 없음)를 기준으로 한다.

### 핵심 전략: 두 가지 단순화

**① 조도센서 모듈(PCF8591T) — 브레드보드 밖으로 뺀다**  
I2C 4핀(VCC/GND/SDA/SCL)만 사용, 점퍼선 4개로 Pi에 직접 연결.

**② 부저 — 트랜지스터 없이 직결 (3.3V 능동형 부저 사용 시)**  
3~5V 동작 능동형 부저라면 GPIO에서 직접 구동 가능.  
→ 브레드보드에서 3행 추가 절약

이 두 가지를 적용하면 **14행 이내**로 모든 부품 배치 가능.

---

### 전원 공급 방식 (전원 레일 없음)

전원 레일이 없으므로 Pi에서 점퍼선으로 직접 끌어온다.

```
Pi 핀2 (5V)   → 브레드보드 Row 16 col a  (5V 분배 행)
Pi 핀1 (3.3V) → 브레드보드 Row 17 col a  (3.3V 분배 행, 센서용)
Pi 핀6 (GND)  → 브레드보드 Row 15 col a  (GND 분배 행)
```

Row 15~17을 전원 분배 행으로 고정하면 나머지 행에서 짧은 점퍼선으로 전원을 끌어다 쓸 수 있다.

### 구역별 요약

| 행 | 부품 | 비고 |
|----|------|------|
| 1~5 | **7세그먼트** | 중앙 홈 걸쳐서 꽂기, COM 핀 → Row15(GND) |
| 6~7 | 220Ω 저항 ×8 | 한 행에 2개씩 세워서 꽂기, GPIO 점퍼로 연결 |
| 8 | **LED** + 220Ω | GPIO18 → R220 → 애노드, 캐소드 → Row15 |
| 9 | **부저** | 3.3V 부저: GPIO23 → BUZ(+), BUZ(-) → Row15 |
| 10~11 | 2N2222 + 1kΩ | 5V 부저 쓸 경우만 추가 |
| 15~17 | 전원 분배 | GND / 5V / 3.3V 행 |
| (외부) | **조도센서 모듈(PCF8591T)** | I2C 4핀 점퍼선으로 Pi에 직결 |

---

### 조도센서 모듈(PCF8591T) I2C 배선

```
Pi 핀1 (3.3V) ──── 모듈 VCC
Pi 핀6 (GND)  ──── 모듈 GND
Pi 핀3 (SDA)  ──── 모듈 SDA
Pi 핀5 (SCL)  ──── 모듈 SCL
```

> **팁 1**: 저항을 수직으로 세워서 꽂으면 한 행에 2~3개까지 배치 가능.  
> **팁 2**: 7세그먼트 COM 핀(2개)은 Row15(GND)에 짧은 점퍼선으로 연결.  
> **팁 3**: 3.3V 능동형 부저를 구하면 트랜지스터 회로 3행을 아낄 수 있음.
