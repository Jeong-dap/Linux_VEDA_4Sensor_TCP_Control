### 2.1 스레드 구성 (7-8장. pthread)

| 스레드 | 역할 | 생성 시점 | 관련 API |
|-------|------|-----------|----------|
| 메인(데몬) | accept 루프, 클라이언트 연결 수락 | 서버 시작 시 | accept(), pthread_create() |
| 클라이언트 핸들러 | 메시지 수신 → 장치 스레드에 명령 전달 | 클라이언트 접속마다 | recv(), pthread_mutex_lock() |
| LED 제어 | 클라이언트 명령에 따라 LED ON/OFF 및 밝기 조절 | 서버 시작 시 | led_on/off/set_brightness(), pthread_cond_wait() |
| 부저 제어 | 클라이언트 명령 또는 침입 감지 시 부저 ON/OFF | 서버 시작 시 | buzzer_on/off(), pthread_cond_wait() |
| 센서 감시 | 조도센서 폴링 100ms, 조도값 170 이상 시 침입 감지, 5초 후 자동 해제 | 서버 시작 시 | wiringPiI2CRead(), nanosleep() |
| 세그먼트 제어 | 클라이언트 전송 숫자 표시, 1초마다 카운트다운 | ACT_SET_NUMBER 수신 시 | segment_display(), pthread_cancel() |
| 이벤트 수신 (클라이언트) | 서버 이벤트 메시지를 비동기 수신 | 클라이언트 시작 시 | recv(), printf() |

### 2.2 공유 상태 구조체 (7-8장. mutex 동기화)

```c
typedef struct {
    int  alarm_active;      // 경보 활성 여부
    int  led_state;         // 0=off, 1=on
    int  led_brightness;    // BRIGHTNESS_LOW/MID/HIGH
    int  buzzer_state;      // 0=off, 1=on
    int  sensor_blocked;    // 0=정상, 1=차단(침입)
    int  segment_value;     // 현재 표시 숫자 (-1=꺼짐)
    int  client_fds[4];     // 연결된 클라이언트 소켓 배열 (최대 4개)
    int  n_clients;         // 현재 연결 수
    pthread_mutex_t lock;   // 공유 자원 보호
} SystemState;
```

## 4. 기능 명세

### 4.1 자동 경보 흐름 (서버 주도)

```
센서 감시 스레드: 조도센서 폴링 (100ms, nanosleep 사용)
    → 빛 꺼짐 감지 (wiringPiI2CRead → 값 ≥ 임계값 170)
    → pthread_mutex_lock(&state.lock)
    → alarm_active = 1, sensor_blocked = 1
    → pthread_mutex_unlock(&state.lock)
    → LED ON (최대 밝기 BRIGHTNESS_HIGH)
    → 부저 ON (buzzer_on() — buzzer.so)
    → 클라이언트에 이벤트 전송:
        { MSG_EVENT, DEV_SENSOR, EVT_INTRUSION, 0 }
        { MSG_EVENT, DEV_LED,    EVT_ALARM_ON,  0 }
    → 이벤트 로그 기록 (open()+write() 시스템 콜)
```

### 4.2 경보 해제 흐름 (클라이언트 주도)

```
클라이언트: 카운트다운 숫자 N (1~9) 전송
    { MSG_CMD, DEV_SEGMENT, ACT_SET_NUMBER, N }

서버 핸들러:
    → 기존 세그먼트 스레드가 있으면 pthread_cancel() + pthread_join()
    → 새 세그먼트 카운트다운 스레드 생성 (pthread_create)
    → segment_display(N) 호출
    → 매초 N-1, N-2 ... 0 감소
    → 매초 클라이언트에 이벤트 전송:
        { MSG_EVENT, DEV_SEGMENT, EVT_COUNTDOWN, 현재값 }
    → 0 도달 시:
        부저 ON (buzzer.so)
        { MSG_EVENT, DEV_BUZZER, EVT_ALARM_TRIGGERED, 0 }

클라이언트: ACT_ALARM_OFF 전송으로 완전 해제
    { MSG_CMD, DEV_SYSTEM, ACT_ALARM_OFF, 0 }
    → 서버: 부저 OFF, LED OFF, alarm_active = 0
```

### 4.3 수동 장치 제어 (클라이언트 주도)

| 장치 | 제어 항목 | 비고 |
|------|-----------|------|
| LED | ON / OFF / 밝기 3단계 (HIGH·MID·LOW) | 경보 중에도 수동 제어 가능 |
| 부저 | ON / OFF | |
| 조도센서 | 상태 조회 | MSG_QUERY 사용 |
| 7세그먼트 | 숫자(0~9) 표시 + 카운트다운 시작/중지 | 진행 중 새 명령 또는 중지 명령 시 pthread_cancel 후 처리 |

### 4.4 예외 처리

| 상황 | 처리 방법 |
|------|-----------|
| 클라이언트 연결 끊김 (recv = 0) | client_fds 배열에서 fd 제거, n_clients--, 핸들러 스레드 종료 |

### 5.5 데몬 프로세스화 (5-6장. fork/setsid + 시그널)

강의에서 학습한 프로세스 생성(fork)과 시그널 처리를 적용하여 서버를 백그라운드 데몬으로 구동한다.

```c
void daemonize(void) {
    pid_t pid = fork();          // 5장: 자식 프로세스 생성
    if (pid > 0) exit(EXIT_SUCCESS);   // 부모 종료
    if (pid < 0) exit(EXIT_FAILURE);

    setsid();                    // 새 세션 리더 — 터미널 분리
    signal(SIGHUP, SIG_IGN);     // 6장: 시그널 처리

    chdir("/");                  // CWD를 루트로 (3-4장: 파일시스템 이해)
    umask(0);

    // 표준 입출력을 /dev/null로 리다이렉션 (3-4장: 파일 디스크립터)
    int fd = open("/dev/null", O_RDWR);
    dup2(fd, STDIN_FILENO);
    dup2(fd, STDOUT_FILENO);
    dup2(fd, STDERR_FILENO);
    close(fd);
}
```

### 5.6 TCP 서버 소켓 (9장. 네트워크 프로그래밍 + 소켓옵션)

강의에서 학습한 3-Way Handshake 과정이 socket/bind/listen/accept API를 통해 구현된다.

```c
int setup_server(int port) {
    int sfd = socket(AF_INET, SOCK_STREAM, 0);

    // 소켓옵션 강의: SO_REUSEADDR — 서버 재시작 시 TIME_WAIT 포트 즉시 재사용
    int opt = 1;
    setsockopt(sfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));

    struct sockaddr_in addr = {
        .sin_family = AF_INET,
        .sin_port   = htons(port),
        .sin_addr.s_addr = INADDR_ANY
    };
    bind(sfd, (struct sockaddr *)&addr, sizeof(addr));
    listen(sfd, 5);   // TCP 3-Way Handshake 대기 큐 크기
    return sfd;
}
```


### 5.8 이벤트 로그 파일 기록 (3-4장. 파일 입출력 시스템 콜)

강의에서 학습한 파일 입출력 시스템 콜(open/write)과 시간 관련 라이브러리 함수(time/strftime)를 조합한다.

```c
void log_event(const char *msg) {
    // 3-4장: open() 시스템 콜 — O_CREAT|O_APPEND|O_WRONLY
    int fd = open("/tmp/alarm.log", O_CREAT | O_APPEND | O_WRONLY, 0644);
    if (fd < 0) return;

    // 1-2장: 라이브러리 함수(time/strftime)와 시스템 콜(write)의 혼합 사용
    time_t now = time(NULL);
    char timebuf[32];
    strftime(timebuf, sizeof(timebuf), "%Y-%m-%d %H:%M:%S", localtime(&now));

    char line[256];
    int len = snprintf(line, sizeof(line), "[%s] %s\n", timebuf, msg);
    write(fd, line, len);   // write() 시스템 콜 직접 사용
    close(fd);
}
```

로그 출력 예시:
```
[2026-06-01 14:32:10] INTRUSION DETECTED
[2026-06-01 14:32:11] ALARM ON (LED HIGH + BUZZER)
[2026-06-01 14:32:25] COUNTDOWN STARTED: 7
[2026-06-01 14:32:32] COUNTDOWN REACHED 0 - BUZZER TRIGGERED
[2026-06-01 14:33:01] ALARM OFF (manual)
```

### 5.9 클라이언트 시그널 처리 (5-6장. 시그널)

myshell LAB1에서 학습한 시그널 처리 구조를 클라이언트에 적용한다.

```c
void sigint_handler(int sig) {
    printf("\n[클라이언트 종료]\n");
    close(sock_fd);
    exit(EXIT_SUCCESS);
}

// 클라이언트 초기화 시:
signal(SIGINT,  sigint_handler);  // Ctrl+C → 정상 종료 (소켓 close 후 exit)
signal(SIGTERM, SIG_IGN);         // kill 명령 무시
signal(SIGHUP,  SIG_IGN);         // 터미널 종료 무시
signal(SIGPIPE, SIG_IGN);         // 서버 연결 끊김 시 크래시 방지
signal(SIGTSTP, SIG_IGN);         // Ctrl+Z (일시정지) 무시
signal(SIGQUIT, SIG_IGN);         // Ctrl+\ (종료+코어덤프) 무시
```

## 10. 문제점 및 보완 사항 (예상)

| 문제점 | 원인 | 보완 방법 |
|--------|------|-----------|
| 세그먼트 카운트다운 중 새 명령 수신 시 충돌 | 스레드 간 segment_value 공유 | pthread_cancel + pthread_join 후 재생성, mutex 보호 |
| 클라이언트 비정상 종료 시 소켓 자원 누수 | recv() 반환값 0 미처리 | recv() == 0 감지 → close(fd), 스레드 정상 종료 |
| dlopen 경로 문제 (데몬 CWD = `/`) | 데몬화 시 chdir("/") 영향 | 절대 경로 또는 실행 파일 기준 상대 경로 사용 |
| 부저/LED 동시 제어 시 GPIO 충돌 | 여러 스레드 동시 접근 | 각 장치별 mutex 또는 장치 접근 직렬화 |
| 조도센서 노이즈로 인한 오감지 | LDR 반응 시간 편차 | 연속 3회 이상 동일 상태 확인 후 감지 처리 (디바운싱) |
| 포트 재사용 오류 (Address already in use) | TIME_WAIT 상태 | SO_REUSEADDR 옵션 적용 (소켓옵션 강의) |
