================================================================
                 스마트 경보 시스템 — 실행 방법
================================================================

----------------------------------------------------------------
1. 하드웨어 연결
----------------------------------------------------------------

[ LED — GPIO 18 ]
  라즈베리파이 GPIO18 (핀12) ──[220Ω]── LED 애노드(+, 긴 다리)
  LED 캐소드(-, 짧은 다리) ── GND

[ 부저 — GPIO 23 ]
  GPIO23 (핀16) ── 부저(+)
  부저(-) ── GND

[ 조도센서 — PCF8591T I2C 모듈 ]
  모듈 VCC ── 3.3V (핀1)
  모듈 GND ── GND  (핀6)
  모듈 SDA ── GPIO2 SDA (핀3)
  모듈 SCL ── GPIO3 SCL (핀5)
  * I2C 주소: 0x48

[ 7세그먼트 — GPIO 4,17,27,22,5,6,13,19 ]
  * Common Anode 타입 (COM = VCC, 세그먼트 LOW=ON)
  * 10핀 기준: 좌측 하단부터 1~5, 우측 상단부터 6~10

  세그먼트 물리핀  역할   라즈베리파이 연결
  ─────────────────────────────────────────
  핀 1  (e)  ────────── GPIO5  (핀29)
  핀 2  (d)  ────────── GPIO22 (핀15)
  핀 3  (COM)────────── 미연결
  핀 4  (c)  ────────── GPIO27 (핀13)
  핀 5  (dp) ────────── GPIO19 (핀35)
  핀 6  (b)  ────────── GPIO17 (핀11)
  핀 7  (a)  ────────── GPIO4  (핀7)
  핀 8  (COM)──[220Ω]── 3.3V   (핀1 또는 핀17)
  핀 9  (f)  ────────── GPIO6  (핀31)
  핀 10 (g)  ────────── GPIO13 (핀33)

----------------------------------------------------------------
2. 소스코드 가져오기 (우분투)
----------------------------------------------------------------

  git clone https://github.com/Jeong-dap/Linux_VEDA_4Sensor_TCP_Comtrol
  cd Linux_VEDA_4Sensor_TCP_Comtrol

----------------------------------------------------------------
3. 빌드 (우분투)
----------------------------------------------------------------

  # 크로스컴파일러 설치 (최초 1회)
  sudo apt install gcc-aarch64-linux-gnu

  # 빌드
  make

  # 빌드 산출물
  # - alarm_server  : 라즈베리파이용 서버 바이너리 (ARM64)
  # - alarm_client  : 우분투용 클라이언트 바이너리 (x86_64)
  # - lib/*.so      : 공유 라이브러리 (ARM64)

----------------------------------------------------------------
4. 라즈베리파이 사전 설정 (최초 1회)
----------------------------------------------------------------

  # 라즈베리파이에서 I2C 활성화
  sudo raspi-config
  → Interface Options → I2C → Enable

  # WiringPi 설치 확인
  gpio -v

  # Node.js 설치 (최초 1회)
  curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
  sudo apt install -y nodejs

----------------------------------------------------------------
5. 라즈베리파이로 배포 (우분투)
----------------------------------------------------------------

  make deploy

  # 전송 항목:
  # - alarm_server       → ~/Project/
  # - lib/*.so           → ~/Project/lib/
  # - web/server.js      → ~/Project/web/
  # - web/index.html     → ~/Project/web/
  # - web/package.json   → ~/Project/web/

----------------------------------------------------------------
6. 라즈베리파이에서 서버 실행
----------------------------------------------------------------

  # C 서버 실행 (데몬으로 백그라운드 동작)
  cd ~/Project
  ./alarm_server

  # 서버 실행 확인
  ps aux | grep alarm_server
  cat /tmp/alarm.log

  # 웹 브리지 실행 (별도 터미널)
  cd ~/Project/web
  npm install    # 최초 1회
  node server.js

----------------------------------------------------------------
7. 클라이언트 실행
----------------------------------------------------------------

  [ CLI 클라이언트 — 우분투 ]
  ./alarm_client <RPI IP Address>

  [ 웹 브라우저 ]
  http://<RPI IP Address>:60000

----------------------------------------------------------------
8. CLI 메뉴
----------------------------------------------------------------

  [1] LED 제어        — ON / OFF / 밝기 3단계 (LOW·MID·HIGH)
  [2] 부저 제어       — ON / OFF / 멜로디 재생
  [3] 세그먼트 제어   — 1~9 카운트다운 시작 / 10 중지
  [4] 상태 조회       — LED / 부저 / 센서 상태
  [5] 조도 수치 확인  — 현재 조도값 (0~255)
  [6] 도움말
  [0] 종료 (Ctrl+C)

----------------------------------------------------------------
9. 서버 종료
----------------------------------------------------------------

  # 라즈베리파이에서
  pkill -f alarm_server

  # 웹 브리지 종료
  Ctrl+C (node server.js 실행 중인 터미널)
